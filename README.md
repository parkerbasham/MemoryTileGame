# Color Matching Memory Game
My final project is a game where the player attempts to match pairs of tiles based on color. 
The basic functionality is that the user begins the game and the tiles flash colors, then are 
set to display white. The user then selects pairs of tiles based on memory. If they match colors, 
they remain colored, otherwise they return to white to be played again. 

## How to Play 
When the app launches, the user must hit New Game to start a game; otherwise, the tiles and the hint button
will not do anything. When the user starts a game, the tiles will briefly flash colors and then return to white. 
After that, the user can start clicking tiles to check for matches. If the user selects two tiles, plays will go up 
by 1. If the user finds a matching pair of tiles, matches will go up by 1. If the user needs help, they can hit
the Hint button which will flash the colors again and then return unmatched tiles to white.
